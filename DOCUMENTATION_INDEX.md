## 📞 Support Resources

### Common Questions
**Q: Where do I access the reports?**
A: Click the 📈 Reports button in the Admin/Staff dashboard sidebar.

**Q: How do I search reports?**
A: Type in the search field that appears in applicable tabs (Stock by Course, Low Stock Items).

**Q: Where are exported files saved?**
A: Check the /reports/ folder in the project root. Path shown in success notification.

**Q: Can I open CSV files in Excel?**
A: Yes! CSV files open directly in Excel or import as sheets.

**For more Q&A**: See [FEATURE_VERIFICATION_GUIDE.md](docs/features/FEATURE_VERIFICATION_GUIDE.md#-troubleshooting)
